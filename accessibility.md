# Accessibility Statement

sdfkjh.com is built to be usable by everyone, including people with disabilities.

## Conformance status

This site aims to meet WCAG 2.2 Level AA, the technical standard most U.S. accessibility guidance points to. It is substantially conformant with that standard, with any exceptions noted under Known limitations below.

## What is in place

-   Semantic landmarks and a logical heading order on every page.
-   A skip-to-content link as the first focusable element.
-   Text and interface colors that meet AA contrast levels.
-   Full keyboard operation, with a visible focus indicator that is never removed without a replacement.
-   Descriptive text alternatives on meaningful images; decorative images marked as such.
-   A declared page language.
-   Reduced-motion support: animations and visual effects honor your browser's reduced-motion setting.

## Known limitations

The homepage includes an interactive playground: a command console and a visual-effects lab, built for demonstration. These are optional and sit alongside the main content. If any part of the playground is difficult to use, the information on the page does not depend on it.

## Get in touch

If you have trouble using any part of this site, or want information in another format, email [info@sdfkjh.com](mailto:info@sdfkjh.com) and we will help.
