Math-driven color & type

Three formulas for generating palettes and scales from a single input. Every swatch and size below is computed live from the formula. Change the input on the right and watch it regenerate.

Test page. Not linked from the site, marked noindex. These formulas set a defensible floor, not a finished design. Contrast and rhythm still get adjusted by eye afterward.

Formula 01

Fibonacci hue palette

From one base color in HSB, step the hue by Fibonacci numbers (5, 8, 13, 21) times a spacing constant. Saturation is nudged per swatch so the set reads connected, not like a wheel sample.

Input

Formula 02

Golden-ratio accent & support

Rotate the primary hue by the golden angle (360 − 360 ÷ 1.618 = 137.5°) to find an accent, then drop the primary's saturation ~60% for a quiet support shade.

Input

Formula 03

Golden-ratio type scale

Multiply up from body size by a fixed ratio for each step in the hierarchy. 1.618 is dramatic, good for hero and landing; switch to a calmer ratio to see why dense UI usually wants one.

Input

Where these break: the golden-angle accent lands near a split-complement and can feel jarring at full chroma. The support desaturation is what keeps the pair usable. A 1.618 type scale grows fast (16→26→42→68): fine for a hero, often too aggressive for dense UI, where 1.2–1.333 reads calmer. And all three ignore contrast. Every generated pair still needs a WCAG check.
