[ ~ ]thesis

Two disciplines, one practice. Brand work shapes how a thing sounds and looks. Web work makes it actually run somewhere. I treat both as systems — built once, shipped everywhere, and made to hold up under attention.

[ 01 ]left hand

brand identity

Marks, palettes, typography, and the systems that hold them together. One source of truth carried from screen to print to inbox — a brand that reads the same wherever it lands.

  • wordmarks and visual identity systems
  • palette, typography, voice as a set
  • one source of truth, ready to ship

[ 02 ]right hand

web development

Sites built with intent. Whether one page or many, the goal is the same: legible code, fast pages, accessible by default, maintainable five years from now.

  • single page to full multi-page site
  • modern hosting, fast by default
  • accessibility, SEO, performance baked in

[ 03 ]both hands

Building systems since 2003. Brand pipelines and infrastructure are the same job at different layers — read the system, make it legible, make it ship. The duality in the brand is real: left hand meets right hand at the home row.
