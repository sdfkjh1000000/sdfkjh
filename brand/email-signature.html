How to install in Gmail:
1. Click anywhere inside the dashed box below
2. Select all (Ctrl+A) — selects only the signature, not this box
3. Copy (Ctrl+C)
4. Open Gmail → gear icon → See all settings → General tab → scroll to Signature
5. Click Create new (or edit existing) → name it (e.g. "sdfkjh") → click into the editor → Ctrl+V
6. Set "Signature defaults" below: pick "sdfkjh" for both FOR NEW EMAILS USE and ON REPLY/FORWARD USE if you want it on every send
7. Scroll to bottom → Save Changes

Notes for future-you:
- Image is loaded from https://sdfkjh.com/apple-touch-icon.png (the live favicon). If sdfkjh.com goes down, the image breaks for new sends and possibly cached views in some clients. Mitigation: re-upload via Gmail's "Insert image" button to host on Google's CDN instead, or replace the URL in the source.
- Display name "Mike Rhodes" inside the signature does NOT change Gmail's sender field ("Michael R" right now). To change that: Gmail Settings → Accounts → Send mail as → edit your address → Name field.
- To replace this signature later: edit this file, re-open in browser, copy-paste into Gmail again. The Gmail signature editor doesn't sync from anywhere.
